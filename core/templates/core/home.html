How it works

Every claim is a rung on the ladder.

A new worker does real work from day one. RUNG stands beside them, then steps back one rung at a time.

{% include "core/partials/shapes/molecule.html" with class="mt-8 hidden w-32 animate-float-slow lg:block" %}
  1. 1

    {% icon "clipboard-check" "size-6" %}Start from the real claim

    RUNG opens with the claim, the provider's note, and the payer's rules already in front of it. There is no blank prompt to fill in.

  2. 2

    {% icon "scan-search" "size-6" %}See what to fix, and why

    The review points to the exact field, explains the problem in plain words, and names the rule it came from. Clean claims are simply marked ready.

  3. 3

    {% icon "trending-up" "size-6" %}Get less help as you improve

    Three correct claims in a row in a skill area and the help steps down. A miss brings it back. The Skill Passport shows the climb.

  4. 4

    {% icon "life-buoy" "size-6" %}Bring in a specialist when it takes one

    One click sends the full case. The specialist's fix is saved to a shared Case Library, so the next worker sees it on a similar claim.

{# ---------- Help that fades: a small interactive demo ---------- #}

Help that fades

The same issue, three ways.

A general chatbot gives the same help forever. RUNG gives less help in each skill area as the worker proves they can do it. Try the three levels.

  • {% icon "book-open-check" %}Full help explains the problem and gives the exact fix.
  • {% icon "message-circle-question-mark" %}Guided asks one question that leads to the fix.
  • {% icon "target" %}Minimal names only the field. The answer is one click away if needed.
